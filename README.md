# Windswept — Spearbound

The current game is an original **2D side-scrolling Warrior and Thief RPG** for **Godot Web Editor 4.7.2**.

Download **Side-Scroller-Warrior.zip** from this repository using GitHub's file download button. Choose it under **Preload project ZIP** in the Godot Web Editor, install the imported project, and click **Run Project**. Do not import the repository-wide Code → Download ZIP: the repository also preserves the earlier crypt prototype.

Current project source: [`side_scroller/`](side_scroller/). Full controls and progression guide: [`side_scroller/README.md`](side_scroller/README.md).

Default controls: **arrows** move, **Up** interacts, **Shift** jumps/double jumps, **Space** attacks, **Z/X/C** cast assigned skills. **I** opens Inventory, **M** Map, **K** Skills and **S** Stats; press again to close. Rebind all keys in Controls.

Menus now use silver frames, blue headers, green stat rows, a draggable title bar and an equipment grid. Damage numbers stack with orange/yellow normal hits, deep-red crits and purple incoming HP loss. Enemies have visible levels and level-scaled contact, melee and projectile damage, reduced by armor.

Includes a 65-map world with 32 safe towns/regions, an atlas with travel directions, themed scenery, regional enemy levels and loot tiers, Willowbridge, Whisperwood, Briar Hollow and the Rootwarden miniboss, original chibi characters and classic cartoon scenery, damage numbers, double jump, XP, loot, equipment, +1/+5/All stat allocation with a confirmable draft, skill ranks, separate Warrior/Thief character slots, sword starters, a short Driving Thrust lunge, eight-frame walking cycles, Warrior or Thief advancement at 10 and Warrior's Spearman advancement at 30, configurable controls, and local saves/JSON backups. Thief advancements now reach Night Lord at 100, with increasing basic stars and third-job Shadow Partner. Warrior third/fourth jobs and Hyper remain future content. Level cap is 100.

Try the throwing-star Thief through **Menu → Characters → Play / Continue: Thief**. Your Warrior save stays in its own slot. Thief first job unlocks Shadow Fan. Basic attacks throw 1/2/3/4 stars by job; Hermit at 60 unlocks a 60-second Shadow Partner on C that mirrors your throws. Twin Stars has been removed.

Full town names and travel guide: [World guide](side_scroller/WORLD_GUIDE.md). This is the first playable world pass; Pirate content is excluded and character artwork is unchanged.

The original 3D crypt project remains at the repository root for preservation; the new standalone ZIP contains only the new 2D project.
